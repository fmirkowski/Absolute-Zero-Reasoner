# 🧠 Simple and Hackable Absolute-Zero-Reasoner Implementation

This is an experimental implementation of the [Absolute Zero paradigm](https://arxiv.org/pdf/2505.03335), in which a single model learns to propose tasks that maximize its own learning progress and improves reasoning by solving them, without relying on ANY EXTERNAL DATA, but only a verifiable environment (like Python) in which self-play behavior is established.


## Current Status: Work in Progress 🚧

This project is actively under development. Currently implementing:

- Group Relative Policy Optimization (GRPO) to test and validate the solver component
